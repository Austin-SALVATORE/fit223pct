# Phase 1 --- Home Foundation (Coach Specification v3)

## Goal

This program is designed for the first three weeks of the user's body
recomposition journey.

Objectives (in priority order):

1.  Build training consistency.
2.  Learn movement quality.
3.  Preserve muscle while reducing body fat.
4.  Establish progressive overload.
5.  Avoid excessive fatigue.
6.  Prepare for the Phase 2 Gym transition.

This is **not** a bodybuilding specialization phase. It is a general
strength and hypertrophy foundation using only home equipment.

------------------------------------------------------------------------

# Weekly Philosophy

The previous Session A / Session B structure is retired.

Every training day should have a clear identity. The user should always
be able to answer:

> "What did I train today?"

Training identity is more important than simply listing completed
exercises.

# Tuesday --- Recovery

Tuesday is permanently reserved as a recovery day because it is one of
the user's office days. Recovery is driven by lifestyle as well as
physiology.

Recovery tasks:

-   Walk 6,000--10,000 steps
-   Stretch 10--15 minutes
-   Meet daily hydration goal
-   Meet daily protein target
-   Sleep at least 7.5 hours

No resistance training.

# Progression Rules

## Compound Movements

Use a three-set ascending ladder.

Progression is determined entirely by successful completion of the prescribed pyramid.

If all prescribed sets and repetitions are completed with good technique, increase the working weight during the next scheduled session.

**No RIR target is used in this program.**

## Isolation Movements

Use two straight working sets.

Increase weight only after consistently reaching the top of the
repetition range.

------------------------------------------------------------------------

# Program Principles

1.  Every training day has a single identity.
2.  Compound lifts always come first.
3.  Isolation follows compounds.
4.  Core finishes the workout.
5.  Recovery is scheduled according to the user's lifestyle, not only
    muscle recovery.
6.  Every major muscle group receives direct weekly stimulus.
7.  The program prioritizes long-term adherence over short-term
    intensity.
