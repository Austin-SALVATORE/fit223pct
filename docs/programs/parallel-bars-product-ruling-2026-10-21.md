# [Owner product ruling — received verbatim 21 Oct 2026, pasted in chat. Answers the board question "Which art and equipment labelling do you accept for the three parallel-bar movements?" with a third option of the owner's own. Governs Phase 2 of the Mesocycle 2 optimization.]

**[Product ruling — Parallel Bars equipment and exercise illustrations]**

Decision: **Option 3 — introduce a dedicated Parallel Bars equipment token.**

However, exercise illustration generation must NOT block the revised Full Body program deployment.

### 1. Equipment taxonomy

Introduce one reusable equipment token:

- EN: Parallel bars
- FR: Barres parallèles
- ZH: 双杠

Assign it to:

- Parallel Bar Dip
- Inverted Row — for the parallel-bar variant used in this program
- Supported Knee Raise

Keep `bodyweight` as the exercise loading classification where appropriate.

**Equipment requirement and loading method are separate concepts.**

Do not create three movement-specific equipment tokens.

Do not add a new equipment-confirmation workflow as part of this change.

### 2. Exercise illustrations

**Parallel Bar Dip**

Do not use the existing straight-bar dip illustration as if it were an accurate representation of parallel-bar dips.

Straight-bar and parallel-bar dips have different hand positions and movement geometry.

**Inverted Row**

The existing machine-bar illustration is provisionally acceptable only if it clearly communicates the same movement mechanics without misleading the athlete about the required setup.

It may be reused temporarily with accurate parallel-bar setup cues.

**Supported Knee Raise**

A missing illustration is acceptable temporarily.

Display the movement name, prescription and technique cues without substituting an unrelated exercise image.

### 3. Future illustration batch

Create an illustration backlog for:

1. Parallel Bar Dip — correct two-parallel-bar setup.
2. Inverted Row — correct freestanding parallel-bar setup.
3. Supported Knee Raise — correct straight-arm support and knee-raising positions.

All future artwork should follow the existing Fit223 illustration style and independent anatomical review process.

No unrelated placeholder image should be used merely to achieve visual completeness.

### 4. Release boundary

The revised Full Body program may ship before all three illustrations are ready, provided:

- exercise names are accurate;
- equipment requirements are accurate;
- prescriptions and cues are complete;
- the actual apparatus setup has been validated;
- missing or provisional artwork does not misrepresent movement technique.

Do not delay a training-program improvement solely for illustration production.

### 5. Scope

Keep this change narrow.

No broad equipment taxonomy redesign, no new exercise player, no additional progression engine and no unrelated Library migration.

The equipment token should be reusable for future parallel-bar exercises rather than implemented as three special cases.
