## CQ2 — Starting weight for ladder exercises during substitution

**Decision: Use the last valid logged weight at the SAME RUNG POSITION.**

Do not use the heaviest or final set as the initial weight for every set.

Example, previous Barbell Bent-Over Row:

| Rung | Previously logged | Suggested when substituted |
|---|---|---|
| 1 | 17.75 kg × 12 | 17.75 kg |
| 2 | 21.75 kg × 10 | 21.75 kg |
| 3 | 25.75 kg × 8 | 25.75 kg |
| 4 | 29.75 kg × 6 | 29.75 kg |

Preserve the order of the substitute exercise's actual loading pattern.

Rules:

- Match by set/rung position.
- Use only valid historical performance of the substitute exercise.
- Do not apply the original exercise's weight or increment.
- Do not use the heaviest historical load as the default first-set load.
- If there is no corresponding valid rung, leave that weight without a historical suggestion rather than guessing.
- The athlete remains free to adjust any suggested load.

This rule concerns the starting suggestion during substitution. It must not create an independent automatic progression mechanism.

## CQ3 — Which historical logs are valid for substitution suggestions?

**Decision: Exclude Easier Day logs and unrelated program phases.**

Use the most recent valid, completed, normal-day performance within the current compatible progression context.

Exclude:

- Easier-day sessions.
- Misidentified exercise entries.
- Corrupted or clamped loads.
- Substitution records that do not establish valid independent progression history.
- Unrelated program phases without an explicitly approved carry-forward relationship.

The "Last time" display may continue showing the athlete's actual most recent performance for historical context.

However, **the displayed historical fact and the suggested starting load are not necessarily the same thing**.

The suggested load must use the last eligible performance, not simply the chronologically newest record.

If no valid performance exists, do not invent a historical suggestion.

## CQ4 — Swaps using the same implement

**Decision: Refine the current behavior. Apply the exercise-specific suggestion rule consistently to ALL substitutions.**

Do not preserve the original slot's load merely because both exercises use dumbbells.

Example:

Dumbbell Bench Press → Incline Dumbbell Press

Although both exercises use dumbbells, they are different movements and may have different appropriate working loads.

Therefore:

- Prefer the substitute's own last valid completed normal-session load.
- Match the appropriate rung position.
- Preserve the substitute's load convention and increments.
- If there is no valid substitute history, do not automatically copy the original exercise's load.
- Leave the weight for explicit athlete selection instead.

This is a deliberate refinement of the earlier cross-implement ruling.

**The governing rule is now exercise-specific history, regardless of whether the implement changes.**

Keep this implementation simple. No conversion formula is required.

## CQ6 — Weighted Dips using a dumbbell held between the legs

**Decision: NOT APPROVED as a standard loading method. Keep D8 Conditional / not ready for program use.**

Holding an unsecured loaded dumbbell between the legs introduces avoidable risks:

- The dumbbell may slip or fall.
- Grip or leg fatigue may cause loss of control.
- The load can swing during movement.
- An unexpected shift can affect balance on the freestanding bars.

Do not add this configuration as an approved Fit223 exercise variation.

The preferred progression for now is:

1. Establish controlled bodyweight Dips.
2. Improve repetitions and movement quality.
3. Increase difficulty only when the current prescription is consistently manageable.
4. Consider purpose-built weighted-dip equipment later, subject to apparatus compatibility and verified loading limits.

The TS 100's rated capacity must not be interpreted as unrestricted approval for added external weight.

No weighted Dip prescription is authorized in the current program.
